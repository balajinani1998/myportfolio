# Balaji Mamilla - Personal Portfolio 🚀

Personal portfolio website for **Balaji Mamilla** — AWS DevOps Engineer & Cyber Security IT Professional.

## 🛠️ Tech Stack

- **Frontend:** React 18, TypeScript, Vite
- **3D & Physics:** Three.js, React Three Fiber, React Three Drei, Rapier Physics
- **Animation:** GSAP, ScrollTrigger, ScrollSmoother, SplitText
- **Styling:** CSS3, Modern Responsive Layout

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
```
